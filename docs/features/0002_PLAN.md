# Feature Plan: Show Catch-Up Reps When Behind

## Description

When a user is behind on their workout challenge, the Telegram bot should display information about how many additional reps they need to perform to catch up to the expected progress for that day. This helps users understand exactly what they need to do to get back on track.

## Files to Modify

### `app/services/workout_service.py`

**Function: `get_exercise_stats_and_message`**

Current behavior (lines 68-142):
- Calculates status using `calculate_status()` function
- Returns formatted message with progress bar and statistics
- Message includes day number, today's total, cumulative total, and progress percentage

Required changes:
1. After calculating `status` (line 104), add logic to calculate catch-up reps when status is "behind"
2. Calculate expected total: `expected = daily_target * day_number if daily_target else (target_total / total_days) * day_number`
3. Calculate catch-up amount: `catch_up_reps = max(0, int(expected - new_cumulative))`
4. Modify message formatting to include catch-up information when status is "behind"

**Function: `calculate_status`**

Current behavior (lines 52-66):
- Calculates expected progress and compares to cumulative total
- Returns status: "ahead", "behind", or "on_track"

No changes needed - existing logic already determines when user is behind.

**Algorithm for catch-up calculation:**

```
1. Calculate expected progress (same as calculate_status):
   - If daily_target exists: expected = daily_target * day_number
   - Else: expected = (target_total / total_days) * day_number

2. Calculate deficit: deficit = expected - cumulative_total

3. If status == "behind" and deficit > 0:
   - catch_up_reps = ceil(deficit)  # Round up to next whole number
   - Add to message: "Need {catch_up_reps} more to catch up!"
```

**Message format changes:**

Current format:
```
{emoji} <b>{display_name}</b>
Day {day_number}/{total_days} • Today: {new_today_total} • Total: {new_cumulative}/{target_total}
[{bar}] {int(progress_percent * 100)}%
```

New format when behind:
```
{emoji} <b>{display_name}</b>
Day {day_number}/{total_days} • Today: {new_today_total} • Total: {new_cumulative}/{target_total}
[{bar}] {int(progress_percent * 100)}%
Need {catch_up_reps} more to catch up!
```

## Implementation Notes

- Catch-up calculation should use `math.ceil()` to round up to the next whole rep (users can't do fractional reps)
- Only show catch-up message when status is "behind" (not when "on_track" or "ahead")
- No database schema changes required
- No changes needed to other functions or message parsing logic
- Maintain existing progress bar and percentage display
- Catch-up message should appear on a new line after the progress bar for clear readability
