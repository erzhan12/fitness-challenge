# 0007: Migrate from Supabase to Django ORM

## Overview

Migrate the fitness-challenge application from Supabase (supabase-py client) to Django ORM, following the repository pattern established in the [habit-reward](https://github.com/erzhan12/habit-reward) reference project. FastAPI remains the web framework; Django is used solely for ORM and migrations.

**Key Constraints:**
- Keep `supabase` in `pyproject.toml` for data migration
- FastAPI continues to handle HTTP routing
- Django ORM handles all database operations
- Repository pattern abstracts database access
- Async support via `sync_to_async`

---

## Current Architecture

### Database Tables (Supabase/PostgreSQL -> SQLite)

| Table | Purpose |
|-------|---------|
| `exercise_types` | Exercise definitions (name, emoji, unit, aliases) |
| `exercise_challenges` | Time-bounded fitness goals |

## Phase 2: Repository Pattern

### 2.1 Repository Classes

**File: `src/core/repositories.py`**

Following the habit-reward pattern with:
- Async methods wrapping Django ORM via `sync_to_async`
- Global singleton instances
- Type flexibility (accept model instances or dicts)

#### ExerciseTypeRepository

Methods:
- `get_all(is_active: bool = None) -> List[ExerciseType]`
- `get_by_id(id: int) -> Optional[ExerciseType]`
- `get_by_name(name: str) -> Optional[ExerciseType]`
- `create(data: dict) -> ExerciseType`
- `update(id: int, data: dict) -> Optional[ExerciseType]`
- `get_by_ids(ids: List[int]) -> List[ExerciseType]`

#### ExerciseChallengeRepository

Methods:
- `get_all(filters: dict = None) -> List[ExerciseChallenge]`
- `get_by_id(id: int) -> Optional[ExerciseChallenge]`
- `get_active_for_type(exercise_type_id: int, target_date: date) -> Optional[ExerciseChallenge]`
- `get_current_active(target_date: date) -> List[ExerciseChallenge]`
- `create(data: dict) -> ExerciseChallenge`
- `update(id: int, data: dict) -> Optional[ExerciseChallenge]`

#### ExerciseLogRepository

Methods:
- `get_all(filters: dict = None, limit: int = 50, offset: int = 0) -> Tuple[List[ExerciseLog], int]`
- `get_by_id(id: int) -> Optional[ExerciseLog]`
- `get_cumulative_count(exercise_type_id: int, challenge_id: int = None, up_to_date: date = None) -> int`
- `get_today_count(exercise_type_id: int, date: date, challenge_id: int = None) -> int`
- `create(data: dict) -> ExerciseLog`
- `delete(id: int) -> Optional[ExerciseLog]`
- `get_last_log(exercise_type_id: int) -> Optional[ExerciseLog]`

#### UserStatsRepository

Methods:
- `get_all() -> List[UserStats]`
- `get_by_exercise_type(exercise_type_id: int) -> Optional[UserStats]`
- `get_or_create(exercise_type_id: int) -> UserStats`
- `update(id: int, data: dict) -> UserStats`
- `increment_total(exercise_type_id: int, count: int, log_date: date)`
- `decrement_total(exercise_type_id: int, count: int)`

### 2.2 Global Repository Instances

## Phase 3: Service Layer Migration

### 3.1 Update `src/api/services.py`

Replace all `get_supabase()` calls with repository methods.

**Before (Supabase):**
```python
def list_exercise_types(is_active=True):
    sb = get_supabase()
    query = sb.table("exercise_types").select("*")
    if is_active is not None:
        query = query.eq("is_active", is_active)
    res = query.execute()
    return [ExerciseTypeOut(**row) for row in res.data]
```

**After (Repository):**
```python
async def list_exercise_types(is_active=True):
    types = await exercise_type_repo.get_all(is_active=is_active)
    return [ExerciseTypeOut.model_validate(t.__dict__) for t in types]
```

### 3.2 Function Mapping

| Current Function | Repository Method(s) |
|-----------------|---------------------|
| `list_exercise_types()` | `exercise_type_repo.get_all()` |
| `get_exercise_type(id)` | `exercise_type_repo.get_by_id()` |
| `create_exercise_type(data)` | `exercise_type_repo.create()` |
| `update_exercise_type(id, data)` | `exercise_type_repo.update()` |
| `list_challenges(filters)` | `challenge_repo.get_all()` |
| `get_challenge(id)` | `challenge_repo.get_by_id()` |
| `get_active_challenge_for_type()` | `challenge_repo.get_active_for_type()` |
| `list_current_active_challenges()` | `challenge_repo.get_current_active()` |

## Phase 6: Data Migration Script

### 6.1 Migration Script

**File: `scripts/migrate_data.py`**

```python
"""
Migrate data from Supabase to Django ORM.

Usage:
    uv run python scripts/migrate_data.py

Prerequisites:
    - Supabase credentials in .env (SUPABASE_URL, SUPABASE_KEY)
    - Django database configured (DATABASE_URL)
    - Django migrations applied (`uv run python manage.py migrate`)
"""
import os
import sys
import django

# Setup Django before imports
os.environ.setdefault("DJANGO_SETTINGS_MODULE", "src.core.settings")
django.setup()

from supabase import create_client
from src.core.models import ExerciseType, ExerciseChallenge, ExerciseLog, UserStats

def migrate_exercise_types(sb):
    """Migrate exercise_types table."""
    res = sb.table("exercise_types").select("*").execute()
    for row in res.data:
        ExerciseType.objects.update_or_create(
            id=row["id"],
            defaults={
                "name": row["name"],
                "display_name": row["display_name"],
                "emoji": row["emoji"],
                "unit": row.get("unit", "reps"),
                "aliases": row.get("aliases", []),
                "is_active": row.get("is_active", True),
            }
        )
    print(f"Migrated {len(res.data)} exercise types")

def migrate_challenges(sb):
    """Migrate exercise_challenges table."""
    res = sb.table("exercise_challenges").select("*").execute()
    for row in res.data:
        ExerciseChallenge.objects.update_or_create(
            id=row["id"],
            defaults={
                "exercise_type_id": row["exercise_type_id"],
                "challenge_name": row.get("challenge_name", ""),
                "start_date": row["start_date"],
                "end_date": row["end_date"],
                "target_total": row["target_total"],
                "daily_target": row.get("daily_target"),
                "is_active": row.get("is_active", True),
                "is_default": row.get("is_default", False),
            }
        )
    print(f"Migrated {len(res.data)} challenges")

def migrate_logs(sb):
    """Migrate exercise_logs table (in batches)."""
    offset = 0
    batch_size = 1000
    total = 0

    while True:
        res = (
            sb.table("exercise_logs")
            .select("*")
            .range(offset, offset + batch_size - 1)
            .execute()
        )

        if not res.data:
            break

        for row in res.data:
            ExerciseLog.objects.update_or_create(
                id=row["id"],
                defaults={
                    "exercise_type_id": row["exercise_type_id"],
                    "challenge_id": row.get("challenge_id"),
                    "date": row["date"],
                    "timestamp": row["timestamp"],
                    "count": row["count"],
                    "cumulative_total": row.get("cumulative_total"),
                    "day_number": row.get("day_number"),
                    "status": row.get("status"),
                    "raw_message": row.get("raw_message"),
                    "duration_seconds": row.get("duration_seconds"),
                    "notes": row.get("notes"),
                }
            )

        total += len(res.data)
        offset += batch_size

        if len(res.data) < batch_size:
            break

    print(f"Migrated {total} logs")

def migrate_user_stats(sb):
    """Migrate user_stats table."""
    res = sb.table("user_stats").select("*").execute()
    for row in res.data:
        UserStats.objects.update_or_create(
            id=row["id"],
            defaults={
                "exercise_type_id": row["exercise_type_id"],
                "all_time_total": row.get("all_time_total", 0),
                "best_daily_count": row.get("best_daily_count", 0),
                "current_streak": row.get("current_streak", 0),
                "longest_streak": row.get("longest_streak", 0),
                "last_logged_date": row.get("last_logged_date"),
            }
        )
    print(f"Migrated {len(res.data)} user stats")

def verify_counts(sb):
    """Verify record counts match between Supabase and SQLite."""
    from src.core.models import ExerciseType, ExerciseChallenge, ExerciseLog, UserStats

    tables = [
        ("exercise_types", ExerciseType),
        ("exercise_challenges", ExerciseChallenge),
        ("exercise_logs", ExerciseLog),
        ("user_stats", UserStats),
    ]

    print("\nVerifying record counts:")
    all_match = True
    for table_name, model in tables:
        sb_count = len(sb.table(table_name).select("id").execute().data)
        django_count = model.objects.count()
        status = "OK" if sb_count == django_count else "MISMATCH"
        if sb_count != django_count:
            all_match = False
        print(f"  {table_name}: Supabase={sb_count}, SQLite={django_count} [{status}]")

    return all_match

def main():
    from app.config import settings

    sb = create_client(settings.SUPABASE_URL, settings.SUPABASE_KEY)

    print("Starting migration from Supabase to Django ORM (SQLite)...")
    print(f"SQLite database will be created at: data/db.sqlite3\n")

    # Order matters: types first (referenced by challenges and logs)
    migrate_exercise_types(sb)
    migrate_challenges(sb)
    migrate_logs(sb)
    migrate_user_stats(sb)

    # Verify migration
    if verify_counts(sb):
        print("\nMigration complete! All records transferred successfully.")
    else:
        print("\nMigration complete with warnings. Please verify data manually.")

if __name__ == "__main__":
    main()
```
