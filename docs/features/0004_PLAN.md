# Feature 0004: Smart Default Exercise Based on Active Challenge

## Description

When a user has only **one active challenge**, entering just an amount (e.g., "25") should automatically log against that challenge's exercise type, rather than always defaulting to "pushups".

**Current behavior:** User sends "25" → LLM defaults to "pushups" (hardcoded in prompt)
**Desired behavior:** User has only squats challenge → sends "25" → logged as 25 squats

## Files to Modify

### 1. `app/services/openai_service.py`

**Function:** `parse_workout_message()` (lines 31-112)

**Changes:**
- Add new parameter: `default_exercise_name: str = "pushups"`
- Update the system prompt (line 49) to use the dynamic default:
  ```
  # Before
  1. If the user provides a number without an exercise name, default to 'pushups'.

  # After
  1. If the user provides a number without an exercise name, default to '{default_exercise_name}'.
  ```

### 2. `app/services/workout_service.py`

**Function:** `process_incoming_message()` (line 355+)

**Changes:**
- After fetching active challenges (line 422-425), determine the default exercise name:
  - Count active challenges in `challenges_data`
  - If exactly 1 challenge exists → look up its exercise type name
  - Otherwise → use "pushups"
- Pass this default to `parse_workout_message()` call (line 461)

**Logic to add around line 460:**
```python
# Determine default exercise based on active challenges
if len(challenges_data) == 1:
    single_challenge = challenges_data[0]
    default_etype = next(
        (et for et in exercise_types if et.id == single_challenge["exercise_type_id"]),
        None
    )
    default_exercise_name = default_etype.name if default_etype else "pushups"
else:
    default_exercise_name = "pushups"

# Pass to parser
parsed_result = parse_workout_message(text, exercise_types, default_exercise_name)
```

## Algorithm

1. User sends message (e.g., "25")
2. `process_incoming_message` fetches all active challenges
3. Count challenges:
   - **If count == 1:** Get the exercise type for that challenge, use its `name` as default
   - **If count == 0 or > 1:** Use "pushups" as default (existing behavior)
4. Pass default exercise name to `parse_workout_message`
5. LLM uses dynamic default in its parsing logic
6. Exercise is logged against the correct challenge

## Edge Cases

| Scenario | Default Exercise | Behavior |
|----------|------------------|----------|
| 1 active challenge (squats) | "squats" | "25" → 25 squats |
| 1 active challenge (pushups) | "pushups" | "25" → 25 pushups (unchanged) |
| 0 active challenges | "pushups" | Fallback to pushups |
| 2+ active challenges | "pushups" | Ambiguous, keep original default |
| User specifies exercise | N/A | "25 squats" always logs squats |
