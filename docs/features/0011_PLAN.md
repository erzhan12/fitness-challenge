# Feature 0011: Habit-Reward Completion Notification

## Description

When all daily exercises are completed, send a POST request to `habitreward.org/api/v1/habits/{habit_id}/complete` to mark the fitness habit as done in the external habit tracking app.

The `habit_id` and API key should be configurable via environment variables. The notification should only be sent once per day (idempotent), and failures should not block the user experience.

## Algorithm: Notification with Idempotency

1. Check if Habit Reward is configured (both env vars present)
2. Atomically claim the date via `try_mark_habit_reward_sent(today_local)`
   - If claim fails (already sent today), return early
3. POST to `{base_url}/api/v1/habits/{habit_id}/complete` with Bearer auth
4. If POST fails, clear the claim via `clear_habit_reward_sent(today_local)` to allow retry
5. Log result but never raise exceptions (fire-and-forget)
