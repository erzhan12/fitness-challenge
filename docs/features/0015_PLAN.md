# Feature 0015: Rich Habit Reward Telegram Messages

## Description

Enhance the Telegram notification sent after the Habit Reward API responds to `habit_done` to include a visual progress bar for reward pieces and an "achieved" message when all pieces are collected.

## Current Behavior

`_format_habit_reward_message()` shows:
- Habit name + streak + fire emojis
- Reward name (if won) or "No reward this time"
- No progress bar, no "achieved" indicator

## Desired Message Formats

**When reward IS won (e.g., streak=3, reward "Coffee", 4/6 pieces):**
```
✅ Habit completed: Walking
🔥🔥🔥 Streak: 3 days

🎁 Reward: Coffee
📊 Progress: ████████░░░░ 4/6
```

**When reward is won AND all pieces collected (6/6):**
```
✅ Habit completed: Walking
🔥🔥🔥 Streak: 3 days

🎁 Reward: Coffee
📊 Progress: ████████████ 6/6
⏳ Reward achieved! You can claim it now!
```

**When NO reward is won:**
```
✅ Habit completed: Walking
🔥🔥🔥 Streak: 3 days

❌ No reward this time - keep going!
```

## API Response Shape

```python
class HabitCompletionResponse(BaseModel):
    habit_confirmed: bool
    habit_name: str
    streak_count: int
    got_reward: bool
    total_weight_applied: float
    reward: RewardResponse | None = None           # {id, name, pieces_required}
    cumulative_progress: RewardProgressResponse | None = None  # {pieces_earned, pieces_required, claimed, progress_percent}
    user_timezone: str = "UTC"
```

## Files to Change

### 1. `app/services/habit_reward_client.py`

**Add `RewardProgressResponse` model** (new Pydantic model):
- `pieces_earned: int`
- `pieces_required: int`
- `claimed: bool`
- `progress_percent: float`

**Update `HabitCompletionResponse`:**
- Change `cumulative_progress: Optional[dict] = None` to `cumulative_progress: Optional[RewardProgressResponse] = None`
- Add `user_timezone: str = "UTC"` field

### 2. `app/services/workout_service.py`

**Update `_format_habit_reward_message()`:**

When `got_reward=True` and `reward` is not None:
1. Show reward name line: `🎁 Reward: {name}`
2. If `cumulative_progress` is present, build a 12-character-wide progress bar:
   - `filled = round(12 * pieces_earned / pieces_required)` (clamp to 0..12)
   - `bar = "█" * filled + "░" * (12 - filled)`
   - Show: `📊 Progress: {bar} {pieces_earned}/{pieces_required}`
3. If `pieces_earned >= pieces_required`, append: `⏳ Reward achieved! You can claim it now!`

When `got_reward=False`:
- Show: `❌ No reward this time - keep going!` (unchanged)

## Progress Bar Algorithm

```
BAR_WIDTH = 12
filled = round(BAR_WIDTH * pieces_earned / pieces_required)
filled = max(0, min(BAR_WIDTH, filled))  # clamp
bar = "█" * filled + "░" * (BAR_WIDTH - filled)
```
